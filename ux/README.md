# Chatbooks UX walkthrough

A slide-style walkthrough of every customer-facing screen: the screen on the left, what each part does on the right.

Open `index.html` in a browser (no build step, no server needed).

- `←` / `→` move between slides, `G` opens the contents, `M` hides the numbered markers.
- Click a marker to highlight its description; hover a description to highlight its marker.
- `screens/` holds the screenshots (desktop 1440px wide, mobile 390px wide), captured against the running app with a demo business.

All figures come from a throwaway demo business created for the captures.
